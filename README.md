# Project 2A – DevOps CI/CD Pipeline

This project implements a CI/CD pipeline for a Java Maven project using Jenkins, JUnit, JaCoCo, SonarQube and GitHub.

## Current Progress

- Implemented 26 comprehensive JUnit test cases
- Included Mockito in one test case
- Integrated JaCoCo code coverage
- Achieved 100% instruction and branch coverage
- Integrated SonarQube code quality analysis
- Configured the initial Jenkins Build & Test pipeline stage
- Published JUnit test results and JaCoCo coverage report in Jenkins
- Integrated SonarQube analysis and Quality Gate in Jenkins
